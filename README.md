# StudyFlow - Estudo Gamificado

Studio Flow — O ponto de partida para alavancar seus estudos

Studio Flow é um aplicativo web educacional que une inteligência artificial, organização de estudos e gamificação inteligente para transformar a forma como estudantes aprendem, evoluem e constroem disciplina acadêmica.

Mais do que um reforço escolar, o Studio Flow foi criado para ser o primeiro impulso: o lugar onde o estudante entra para se organizar, criar constância, entender conteúdos e decolar no aprendizado — do Ensino Fundamental à faculdade.

Um ambiente profissional, leve e motivador

O Studio Flow foi pensado para ser:

Profissional, confiável e bem estruturado

Visualmente leve e minimalista

Envolvente como um jogo, sem perder o foco educacional

A experiência mistura o melhor de plataformas como Canva, Duolingo, Matific e academias digitais, mas com identidade própria: menos poluição visual, mais clareza e propósito.

Perfil, Avatares e Identidade do Usuário

No Studio Flow, o perfil é parte central da experiência.

O usuário pode personalizar:

Avatares (personagens)

Tipos de nome (faixas, molduras e estilos)

Identidade visual do perfil

Emblemas e conquistas

Esses itens podem ser:

Desbloqueados por nível

Comprados na loja com moedas do jogo

Obtidos em caixas misteriosas

Moedas, Recompensas e Caixas Misteriosas

O Studio Flow possui um sistema de recompensas equilibrado.

Como ganhar moedas:

Realizando atividades diárias

Cumprindo metas de estudo

Lendo livros

Mantendo constância (ofensivas)

Exemplos de atividades:

Estudar 50 minutos com timer integrado

Ler 50 minutos de um livro

Resolver desafios diários gerados por IA

Completar trilhas de aprendizado

Ao cumprir atividades, o usuário recebe:

Moedas

Pontos de progresso

Caixas misteriosas, que podem conter:

Avatares

Itens de perfil

Estilos de nome

Bônus temporários

Recompensas raras (especialmente no início)

Na primeira vez que entra no app, o usuário recebe:

2.000 moedas iniciais

Pontos suficientes para desbloquear itens básicos
Isso cria engajamento imediato e sensação de progresso.

Atividades Diárias Inteligentes

As atividades diárias são geradas por inteligência artificial e adaptadas ao perfil do estudante.

Antes de finalizar o cadastro, o usuário responde perguntas como:

Série / ano escolar

Área de estudo

Objetivos

Dificuldades principais

Essas informações:

Podem ser renovadas a qualquer momento

Possuem uma página específica para atualização anual

Se adaptam à troca de série ou fase acadêmica

As atividades variam do Ensino Fundamental 1 até a faculdade, garantindo longevidade ao usuário dentro da plataforma.

IA Tutora: aprender de verdade

O Studio Flow possui uma IA Tutora, mas com uma regra clara:

Ela não entrega respostas prontas.

A IA:

Explica o caminho

Mostra o raciocínio

Ajuda a entender o “porquê”

Estimula autonomia intelectual

Após o usuário concluir corretamente uma atividade diária, ele pode usar a IA para:

Revisar a solução

Entender erros

Consolidar o aprendizado

Além disso, existe uma área separada de Ferramentas com IA, onde:

A IA pode ajudar de forma mais direta

Explicações aprofundadas são liberadas

O foco é estudo orientado, não cola
